# Замер скорости скачивания

[![tests](https://github.com/computergibs/internet-speed-test/actions/workflows/tests.yml/badge.svg)](https://github.com/computergibs/internet-speed-test/actions/workflows/tests.yml)

Консольный скрипт на Python. Делает 10 запросов подряд к указанному адресу, дожидается полного ответа на каждый и печатает среднее время запроса, общий объём скачанных данных и скорость скачивания.

## Запуск

Нужен Python 3.9 или новее.

```bash
git clone https://github.com/computergibs/internet-speed-test.git
cd internet-speed-test
python -m pip install -r requirements.txt
python speedtest.py https://upload.wikimedia.org/wikipedia/commons/f/ff/Pizigani_1367_Chart_10MB.jpg
```

- В Linux и macOS вместо `python` может понадобиться `python3`.
- Чтобы не ставить зависимость глобально, перед `pip install` создайте виртуальное окружение: `python -m venv .venv`, затем `.venv\Scripts\activate` (Windows) или `source .venv/bin/activate` (Linux, macOS).
- С [uv](https://docs.astral.sh/uv/) хватит одной команды, зависимость указана в самом скрипте ([PEP 723](https://peps.python.org/pep-0723/)): `uv run speedtest.py <url>`.

Единственная зависимость — [certifi](https://pypi.org/project/certifi/), корневые сертификаты для проверки HTTPS ([зачем](#зачем-certifi)). Всё остальное — стандартная библиотека.

### Параметры

| Параметр | По умолчанию | Что задаёт |
|---|---|---|
| `url` | — | адрес файла (`http://` или `https://`), например тяжёлой картинки |
| `-n`, `--requests` | `10` | число запросов |
| `-t`, `--timeout` | `30` | сколько секунд ждать соединения или очередной порции данных |

Справка: `python speedtest.py --help`.

## Единицы измерения

- **Скорость — Мбит/с** (мегабиты в секунду, 1 Мбит = 1 000 000 бит). В этих единицах указывают скорость провайдеры и сервисы вроде Speedtest, так что результат можно сразу сравнить с тарифом. В скобках та же скорость в МБ/с — в них показывают скорость браузеры при скачивании файлов (1 МБ/с = 8 Мбит/с).
- **Объём — МБ** (мегабайты, 1 МБ = 1 000 000 байт), в итоговой строке ещё и точное число байт.
- **Время — секунды.**

Приставки десятичные (СИ), как принято для скорости сети: мега = 10⁶, а не 2²⁰.

## Как считается

- Запросы `GET` идут строго по очереди: следующий начинается только после того, как предыдущий ответ получен целиком.
- **Время запроса** — от отправки запроса до получения последнего байта ответа. Сюда входят DNS, установка TCP- и TLS-соединения (каждый запрос идёт в новом соединении), ожидание сервера и сама передача. Время меряется по `time.perf_counter()` — монотонным часам высокого разрешения.
- **Объём** — сумма размеров тел ответов, без HTTP-заголовков. Сжатие при передаче отключено (`Accept-Encoding: identity`), поэтому объём совпадает с размером файла. Тело читается кусками по 64 КиБ и не копится в памяти, так что размер файла не ограничен.
- **Среднее время** = суммарное время ÷ число запросов.
- **Скорость** = общий объём × 8 ÷ суммарное время ÷ 10⁶, то есть объём ÷ (среднее время × число запросов) — средняя пропускная способность за весь замер. Среднее арифметическое скоростей отдельных запросов было бы завышено: в нём короткие быстрые запросы весили бы столько же, сколько долгие медленные.

Если сервер ответил ошибкой (4xx/5xx), соединение оборвалось, истёк таймаут или пришло меньше данных, чем обещано в `Content-Length`, скрипт сообщает, какой запрос не удался, и завершается с кодом 1: неполные данные в результат не попадают. При неверных аргументах код выхода — 2.

## Точность

- Установка соединения входит во время запроса, поэтому на маленьких файлах скорость получается заниженной. Берите файл от 10 МБ.
- Это скорость скачивания с конкретного сервера в одно соединение. Speedtest качает в несколько потоков с ближайшего сервера, поэтому на быстрых каналах может показать больше.

## Зачем certifi

Запросы делает стандартный `urllib`, а сертификаты HTTPS проверяются по набору Mozilla из certifi — тому же, что у `requests` и `pip`. Без него Python на Windows доверяет системному хранилищу сертификатов как есть, и устаревшие сертификаты, закэшированные там, ломают проверку вполне рабочих сайтов. Так было при разработке: `upload.wikimedia.org` не открывался с ошибкой `certificate has expired` из-за просроченного кросс-сертификата ISRG Root X2 в хранилище Windows. С certifi проверка одинакова на любой ОС.

## Тесты

```bash
python -m unittest -v
```

Тесты поднимают локальный HTTP-сервер, интернет не нужен. Проверяются подсчёт байтов (с `Content-Length` и без), ошибки HTTP, обрыв соединения, недокачанный ответ, таймаут, формулы итогов и разбор аргументов. GitHub Actions прогоняет тесты на Ubuntu и Windows с Python 3.9 и 3.13.
